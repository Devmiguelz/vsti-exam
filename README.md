# Simulacro · Certificación Procesos Críticos VSTI

App de estudio interactiva para preparar la certificación de Procesos Críticos de las Vicepresidencias de Tecnología — Bancolombia.

## Módulos cubiertos

| Módulo | Contenido |
|--------|-----------|
| 🏛️ Modelo Operativo | Federal–State–Local, PHVA, tipos de modelos |
| ⚙️ Gestión de la Configuración | CMDB, CIs, App Code, Hilix |
| 🔄 Gestión de Cambios | Tipos de cambio, Circular 028, Consejo, controles SOX |
| 🚨 Gestión de Incidentes | ANS, causa raíz, prioridad, garantías |
| 🧩 Gestión de Problemas | PKE, workaround, Gartner, gestión proactiva |
| 🛠️ Habilitar y Mantener Soluciones | DoD, GitFlow, pirámide de pruebas, despliegues |

## Funcionalidades

- **Flashcards** con algoritmo de repetición espaciada SM-2
- **Simulacro de examen** con banco de 60 preguntas (10 por módulo)
- **Contenido de lectura** por módulo con tablas, callouts y glosario
- **Ejercicios de emparejar** (2 por módulo)
- **Radar de dominio** con porcentaje de avance por módulo
- **Progreso guardado** en el navegador (localStorage)
- **Exportar / importar progreso** en JSON para respaldo o cambio de dispositivo
- Diseñada para móvil — instalable como PWA en iOS y Android

## Uso

Abre directamente en el navegador — no requiere instalación ni conexión a internet.

El progreso se guarda automáticamente en el navegador. Para transferirlo entre dispositivos usa el botón de exportar en la pantalla de inicio.
